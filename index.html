Credit Card Fraud Detection Using Random Forest

Random Forest classifier on the 284,807-transaction Kaggle dataset (0.17% fraud), using SMOTE on the training set only and RandomizedSearchCV for tuning.

  • Lowering the decision threshold to 0.3 raised fraud recall from 0.78 to 0.84 (124 of 148 frauds caught) at 99.93% accuracy.
  • The cost: false positives rose from 17 to 48.
